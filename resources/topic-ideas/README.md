# Topic ideas

Proposals for explaining established mathematics with a live educational demonstration. No topic has been selected here, and none requires original research.

| Topic | Main focus | Demonstration |
| --- | --- | --- |
| [PageRank](pagerank.md) | Convergence and sensitivity of network rankings | Probability flowing through an editable network |
| [Bayesian change detection](bayesian-stats.md) | Model evidence and uncertainty about one change | Did a coin's bias change? |
| [Gaussian processes](gaussian-processes.md) | Distributions over functions and Bayesian regression | Add observations and update a regression curve and uncertainty band |
| [Hamiltonian Monte Carlo](hamiltonian-monte-carlo.md) | Dynamics, numerical integration and invariant distributions | Compare HMC trajectories with a random-walk sampler |
| [Thompson sampling](thompson-sampling.md) | Exploration, exploitation and regret | Watch competing strategies learn which option is best |
| [Dirichlet processes](dirichlet-processes.md) | Random probability distributions and flexible mixtures | Animate prior group formation and posterior clustering |

The four new Bayesian suggestions came from the group discussion. Gaussian processes offer the most balanced split across linear algebra, probability, statistics and coding. HMC adds a strong dynamics strand; Thompson sampling is more accessible but has little linear algebra; Dirichlet processes are the most demanding and would need a different division of work.

Choose a bounded core and check the expected mathematical depth against the group's previous coursework and the lecturer's guidance. The references are starting points for reading, not a complete bibliography.
