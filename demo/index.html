Instructions

  • You and Bayesian optimisation (BO) start with the same three observations, shown as purple squares.
  • Click the graph to choose an input, then select Evaluate guess to see its function value. BO makes one guess after yours using its own observations.
  • Once you have used your guesses, BO's results are revealed and the winner is crowned.
  • You can explore its decision making process after the match.

What we know about the hidden function

  • The function is smooth on the interval from 0 to 1. Nearby inputs tend to give similar values.
  • The function can have several peaks of different widths. A narrow peak can sit between observations.
  • Values can be close to zero, and high points are typically in the hundreds.

BO Assumptions

  • GP prior. BO starts with a zero-mean Gaussian process and a squared-exponential kernel, a common choice for smooth functions. Evaluations are noise-free.
  • Length scale. BO uses 0.15 as the fixed length scale for correlated function values. This means, for example, it assumes about 0.61 correlation to the function values at x = 0.50 and x = 0.65, which are one length scale apart.
  • Prior standard deviation. BO uses a fixed SD of 200 at each input. For scores on the scale of hundreds, 200 is a rough estimate of uncertainty before seeing any observations.
  • Choosing a guess. BO updates the GP with its observations and chooses the unevaluated grid point with the highest expected improvement over its best observed value.
  • Replay uncertainty. The shaded band runs from the posterior mean minus 1.96σ to the mean plus 1.96σ at each input. The σ shown for the selected input is calculated before evaluation.
